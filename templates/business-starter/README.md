# Business Starter

Astroid's first code-defined template package.

- Template ID: `business-starter`
- Version: `1.0.0`
- Runtime: Astro
- Sections: Hero, About, Services, Features, Testimonials, FAQ, CTA, Contact

The manifest defines stable section types, editable fields and supported layout variants. The production template renderer will consume this manifest and render version-pinned Astro components.
